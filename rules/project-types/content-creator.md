# Content Creator Project Rules

## Scope

适用于公众号文章、小红书图文、短视频脚本、选题策划、内容日历、标题、封面文案、账号定位、爆款拆解和素材整理。

## Working Mode

- 先明确平台、目标读者、账号定位、内容目标、语气、人设边界和发布约束。
- 根据平台调整交付形态：公众号重视结构、论证、标题和转化；小红书重视封面、首图、标题、笔记节奏、标签和图片说明。
- 区分原创观点、引用材料、事实数据和营销表达；需要事实支撑时标注来源或待核验。
- 不编造案例、数据、经历、背书、截图或用户反馈。
- 涉及医疗、法律、金融、投资、教育升学等高风险内容时，降低确定性表达，并提示核验或专业咨询。

## Content Workflow

- 选题先判断读者痛点、平台匹配度、差异化角度和可交付素材。
- 写作先给结构，再产出正文；需要多版本时优先变化标题、开头、角度和 CTA。
- 小红书图片需求应输出封面文案、每页图文脚本、画面构图、素材建议、尺寸比例和导出注意事项。
- 公众号文章应关注标题组、导语、正文层级、小标题、金句、案例、结尾和引导动作。

## Deliverables

- 默认输出可直接发布或可直接交给设计执行的内容，不只给建议。
- 输出中保留可替换字段，例如品牌名、产品名、时间、链接和 CTA。
- 如果素材不足，先交付基于假设的版本，并列出最少需要补齐的素材清单。
