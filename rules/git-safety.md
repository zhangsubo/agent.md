# Git Safety

## Before Editing

- 修改前检查当前分支和工作区状态。
- 可能存在用户未提交改动；不要覆盖、不回退用户已有改动。
- 如果任务会影响已有文件，先确认相关文件是否有未提交变化，并在改动时避开无关内容。

## Commit And Push

- 不在未确认的情况下执行 `git push`。
- 准备提交前，先说明拟提交的变更内容。
- 默认 commit message 使用中文，描述清晰、准确。
- 提交前确认不包含 `Reference_myself/`、密钥、token、私有证书、`.env`、临时文件或本地数据库。

## Risky Operations

- 不执行破坏性命令，例如 `git reset --hard`、批量删除、强制覆盖、生产部署，除非用户明确要求。
- 删除、迁移、发布、推送等高风险动作需要明确确认。
- 同一技术路径连续失败时停止复盘，说明失败原因和替代方案。
